## API Reference

| Prop           | Type                                            | Default           | Description                              |
| -------------- | ----------------------------------------------- | ----------------- | ---------------------------------------- |
| `theme`        | `Parameters<typeof __Buttons>[0]["theme"]`      | Component default | Renderer theme configuration.            |
| `label`        | `string`                                        | Component default | Configures the component's label.        |
| `href`         | `string`                                        | Component default | Configures the component's href.         |
| `variant`      | `"primary" \| "secondary" \| "text"`            | Component default | Configures the component's variant.      |
| `size`         | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "all"` | Component default | Configures the component's size.         |
| `icon`         | `Parameters<typeof __Buttons>[0]["icon"]`       | Component default | Configures the component's icon.         |
| `iconPosition` | `"leading" \| "trailing"`                       | Component default | Configures the component's iconposition. |
| `align`        | `"left" \| "center" \| "right"`                 | Component default | Configures the component's align.        |
