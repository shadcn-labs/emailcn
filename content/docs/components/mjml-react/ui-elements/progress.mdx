## API Reference

| Prop      | Type                                                  | Default           | Description                         |
| --------- | ----------------------------------------------------- | ----------------- | ----------------------------------- |
| `theme`   | `Parameters<typeof __ProgressFull>[0]["theme"]`       | Component default | Renderer theme configuration.       |
| `items`   | `ProgressItem[]`                                      | Component default | Configures the component's items.   |
| `layout`  | `"single" \| "group" \| "columns"`                    | Component default | Configures the component's layout.  |
| `padding` | `"none" \| "padded"`                                  | Component default | Configures the component's padding. |
| `content` | `"minimal" \| "title" \| "description" \| "text-top"` | Component default | Configures the component's content. |
