## API Reference

| Prop        | Type                                            | Default           | Description                           |
| ----------- | ----------------------------------------------- | ----------------- | ------------------------------------- |
| `theme`     | `Parameters<typeof __Avatar>[0]["theme"]`       | Component default | Renderer theme configuration.         |
| `avatars`   | `AvatarItem[]`                                  | Component default | Configures the component's avatars.   |
| `plusCount` | `number`                                        | Component default | Configures the component's pluscount. |
| `size`      | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "2xl"` | Component default | Configures the component's size.      |
| `align`     | `"left" \| "center" \| "right"`                 | Component default | Configures the component's align.     |
