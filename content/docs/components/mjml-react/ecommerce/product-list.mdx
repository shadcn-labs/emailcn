## API Reference

| Prop       | Type                                           | Default           | Description                               |
| ---------- | ---------------------------------------------- | ----------------- | ----------------------------------------- |
| `theme`    | `Parameters<typeof __ProductList>[0]["theme"]` | Component default | Renderer theme configuration.             |
| `products` | `ProductListItem[]`                            | Component default | Supplies the products displayed in rows.  |
| `variant`  | `ProductListVariant`                           | `"basic"`         | Selects the product-row detail treatment. |
