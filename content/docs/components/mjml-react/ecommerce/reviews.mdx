## API Reference

| Prop       | Type                                                                                                                 | Default           | Description                          |
| ---------- | -------------------------------------------------------------------------------------------------------------------- | ----------------- | ------------------------------------ |
| `theme`    | `Parameters<typeof __FullWidthReviews>[0]["theme"]`                                                                  | Component default | Renderer theme configuration.        |
| `items`    | `ReviewItem[]`                                                                                                       | Component default | Configures the component's items.    |
| `layout`   | `"full-width" \| "two-columns" \| "masonry"`                                                                         | Component default | Configures the component's layout.   |
| `identity` | `\| "text"     \| "logo"     \| "avatar-inline"     \| "avatar-centered"     \| "avatar-logo"     \| "avatar-aside"` | Component default | Configures the component's identity. |
| `divider`  | `"none" \| "top" \| "between" \| "bottom"`                                                                           | Component default | Configures the component's divider.  |
| `reverse`  | `boolean`                                                                                                            | Component default | Configures the component's reverse.  |
