## API Reference

| Prop            | Type                                              | Default           | Description                               |
| --------------- | ------------------------------------------------- | ----------------- | ----------------------------------------- |
| `theme`         | `Parameters<typeof __BasicLogoCloud>[0]["theme"]` | Component default | Renderer theme configuration.             |
| `title`         | `string`                                          | Component default | Configures the component's title.         |
| `description`   | `string`                                          | Component default | Configures the component's description.   |
| `logos`         | `LogoItem[]`                                      | Component default | Configures the component's logos.         |
| `layout`        | `"cloud" \| "grid" \| "featured"`                 | Component default | Configures the component's layout.        |
| `appearance`    | `"plain" \| "boxed" \| "outlined" \| "bordered"`  | Component default | Configures the component's appearance.    |
| `alignment`     | `"left" \| "center" \| "right"`                   | Component default | Configures the component's alignment.     |
| `featuredIndex` | `number`                                          | Component default | Configures the component's featuredindex. |
