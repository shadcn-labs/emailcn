## API Reference

| Prop            | Type                                             | Default           | Description                               |
| --------------- | ------------------------------------------------ | ----------------- | ----------------------------------------- |
| `theme`         | `Parameters<typeof __ImageGridHero>[0]["theme"]` | Component default | Renderer theme configuration.             |
| `content`       | `HeroContent`                                    | Component default | Configures the component's content.       |
| `images`        | `HeroImage[]`                                    | Component default | Configures the component's images.        |
| `brand`         | `HeroBrand`                                      | Component default | Configures the component's brand.         |
| `imagePosition` | `"top" \| "bottom"`                              | Component default | Configures the component's imageposition. |
| `offset`        | `boolean`                                        | Component default | Configures the component's offset.        |
