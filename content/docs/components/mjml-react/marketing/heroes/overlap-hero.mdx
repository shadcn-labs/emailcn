## API Reference

| Prop              | Type                                                  | Default           | Description                                 |
| ----------------- | ----------------------------------------------------- | ----------------- | ------------------------------------------- |
| `theme`           | `Parameters<typeof __OverlapContentHero>[0]["theme"]` | Component default | Renderer theme configuration.               |
| `content`         | `HeroContent`                                         | Component default | Configures the component's content.         |
| `images`          | `HeroImage[]`                                         | Component default | Configures the component's images.          |
| `backgroundImage` | `HeroImage`                                           | Component default | Configures the component's backgroundimage. |
| `brand`           | `HeroBrand`                                           | Component default | Configures the component's brand.           |
| `target`          | `"content" \| "image"`                                | Component default | Configures the component's target.          |
| `direction`       | `"left" \| "right"`                                   | Component default | Configures the component's direction.       |
| `gradient`        | `boolean`                                             | Component default | Configures the component's gradient.        |
| `slanted`         | `boolean`                                             | Component default | Configures the component's slanted.         |
