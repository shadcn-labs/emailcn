## API Reference

| Prop                    | Type                             | Default           | Description                                       |
| ----------------------- | -------------------------------- | ----------------- | ------------------------------------------------- |
| `theme`                 | `EmailThemeTokens`               | Component default | Renderer theme configuration.                     |
| `logoSrc`               | `string`                         | Component default | Configures the component's logosrc.               |
| `logoAlt`               | `string`                         | Component default | Configures the component's logoalt.               |
| `logoHref`              | `string`                         | Component default | Configures the component's logohref.              |
| `userName`              | `string`                         | Component default | Configures the component's username.              |
| `userEmail`             | `string`                         | Component default | Configures the component's useremail.             |
| `initials`              | `string`                         | Component default | Configures the component's initials.              |
| `avatarSrc`             | `string`                         | Component default | Configures the component's avatarsrc.             |
| `avatarAlt`             | `string`                         | Component default | Configures the component's avataralt.             |
| `avatar`                | `HeaderWithUserDetailsAvatar`    | Component default | Configures the component's avatar.                |
| `alignment`             | `HeaderWithUserDetailsAlignment` | Component default | Configures the component's alignment.             |
| `pageBackgroundColor`   | `string`                         | Component default | Configures the component's pagebackgroundcolor.   |
| `backgroundColor`       | `string`                         | Component default | Configures the component's backgroundcolor.       |
| `avatarBackgroundColor` | `string`                         | Component default | Configures the component's avatarbackgroundcolor. |
| `headingColor`          | `string`                         | Component default | Configures the component's headingcolor.          |
| `textColor`             | `string`                         | Component default | Configures the component's textcolor.             |
| `mutedTextColor`        | `string`                         | Component default | Configures the component's mutedtextcolor.        |
