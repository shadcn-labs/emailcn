## API Reference

| Prop          | Type                                           | Default           | Description                             |
| ------------- | ---------------------------------------------- | ----------------- | --------------------------------------- |
| `theme`       | `Parameters<typeof __Cta>[0]["theme"]`         | Component default | Renderer theme configuration.           |
| `heading`     | `string`                                       | Component default | Configures the component's heading.     |
| `description` | `string`                                       | Component default | Configures the component's description. |
| `action`      | `{ href: string; label: string }`              | Component default | Configures the component's action.      |
| `images`      | `Array<{ src: string; alt?: string }>`         | Component default | Configures the component's images.      |
| `treatment`   | `"offset" \| "shifted" \| "side" \| "collage"` | Component default | Configures the component's treatment.   |
