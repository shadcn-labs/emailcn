## API Reference

| Prop         | Type                                                                                 | Default           | Description                            |
| ------------ | ------------------------------------------------------------------------------------ | ----------------- | -------------------------------------- |
| `theme`      | `Parameters<typeof __FullWidthImage>[0]["theme"]`                                    | Component default | Renderer theme configuration.          |
| `image`      | `GalleryImage`                                                                       | Component default | Configures the component's image.      |
| `overlay`    | `boolean`                                                                            | Component default | Configures the component's overlay.    |
| `frame`      | `\| "none"     \| "top"     \| "right"     \| "bottom"     \| "left"     \| "sides"` | Component default | Configures the component's frame.      |
| `frameStyle` | `"padding" \| "split" \| "alternate"`                                                | Component default | Configures the component's framestyle. |
