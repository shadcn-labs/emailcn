## API Reference

| Prop             | Type                                             | Default           | Description                                |
| ---------------- | ------------------------------------------------ | ----------------- | ------------------------------------------ |
| `theme`          | `Parameters<typeof __BoxedNumbered>[0]["theme"]` | Component default | Renderer theme configuration.              |
| `heading`        | `string`                                         | Component default | Configures the component's heading.        |
| `items`          | `FaqItem[]`                                      | Component default | Configures the component's items.          |
| `layout`         | `"boxed" \| "collapsed" \| "expanded"`           | Component default | Configures the component's layout.         |
| `marker`         | `"none" \| "number" \| "icon"`                   | Component default | Configures the component's marker.         |
| `alternating`    | `boolean`                                        | Component default | Configures the component's alternating.    |
| `answerPosition` | `"stacked" \| "offset"`                          | Component default | Configures the component's answerposition. |
| `action`         | `FaqAction`                                      | Component default | Configures the component's action.         |
