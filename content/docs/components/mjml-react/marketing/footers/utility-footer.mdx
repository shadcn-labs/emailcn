## API Reference

| Prop              | Type                                                                         | Default           | Description                                 |
| ----------------- | ---------------------------------------------------------------------------- | ----------------- | ------------------------------------------- |
| `theme`           | `Parameters<typeof __SimpleSocialFooter>[0]["theme"]`                        | Component default | Renderer theme configuration.               |
| `brand`           | `FooterBrand`                                                                | Component default | Configures the component's brand.           |
| `socials`         | `FooterSocial[]`                                                             | Component default | Configures the component's socials.         |
| `legal`           | `FooterLegal`                                                                | Component default | Configures the component's legal.           |
| `content`         | `"socials" \| "address" \| "legal" \| "locations" \| "app-stores"`           | Component default | Configures the component's content.         |
| `locations`       | `FooterLocation[]`                                                           | Component default | Configures the component's locations.       |
| `address`         | `string`                                                                     | Component default | Configures the component's address.         |
| `title`           | `string`                                                                     | Component default | Configures the component's title.           |
| `alignment`       | `"left" \| "center" \| "right"`                                              | Component default | Configures the component's alignment.       |
| `columns`         | `1 \| 2`                                                                     | Component default | Configures the component's columns.         |
| `backgroundImage` | `{     src: string;     alt?: string;     position?: "top" \| "bottom";   }` | Component default | Configures the component's backgroundimage. |
