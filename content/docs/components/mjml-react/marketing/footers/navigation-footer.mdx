## API Reference

| Prop            | Type                                               | Default           | Description                               |
| --------------- | -------------------------------------------------- | ----------------- | ----------------------------------------- |
| `theme`         | `Parameters<typeof __TwoColumnFooter>[0]["theme"]` | Component default | Renderer theme configuration.             |
| `brand`         | `FooterBrand`                                      | Component default | Configures the component's brand.         |
| `description`   | `string`                                           | Component default | Configures the component's description.   |
| `menus`         | `FooterMenu[]`                                     | Component default | Configures the component's menus.         |
| `socials`       | `FooterSocial[]`                                   | Component default | Configures the component's socials.       |
| `legal`         | `FooterLegal`                                      | Component default | Configures the component's legal.         |
| `columns`       | `1 \| 2 \| 3`                                      | Component default | Configures the component's columns.       |
| `alignment`     | `"left" \| "center" \| "right"`                    | Component default | Configures the component's alignment.     |
| `logoPosition`  | `"left" \| "right" \| "top" \| "bottom"`           | Component default | Configures the component's logoposition.  |
| `divider`       | `boolean`                                          | Component default | Configures the component's divider.       |
| `oversizedLogo` | `boolean`                                          | Component default | Configures the component's oversizedlogo. |
