## API Reference

| Prop         | Type                     | Default           | Description                            |
| ------------ | ------------------------ | ----------------- | -------------------------------------- |
| `theme`      | `EmailThemeTokens`       | Component default | Renderer theme configuration.          |
| `variant`    | `PaymentTimelineVariant` | Component default | Configures the component's variant.    |
| `amount`     | `string`                 | Component default | Configures the component's amount.     |
| `firstDate`  | `string`                 | Component default | Configures the component's firstdate.  |
| `secondDate` | `string`                 | Component default | Configures the component's seconddate. |
| `thirdDate`  | `string`                 | Component default | Configures the component's thirddate.  |
| `fourthDate` | `string`                 | Component default | Configures the component's fourthdate. |
