## API Reference

| Prop        | Type                                        | Default           | Description                           |
| ----------- | ------------------------------------------- | ----------------- | ------------------------------------- |
| `theme`     | `Parameters<typeof __Featured>[0]["theme"]` | Component default | Renderer theme configuration.         |
| `post`      | `BlogPost`                                  | Component default | Configures the component's post.      |
| `width`     | `"contained" \| "full"`                     | Component default | Configures the component's width.     |
| `dateStyle` | `"none" \| "large"`                         | Component default | Configures the component's datestyle. |
