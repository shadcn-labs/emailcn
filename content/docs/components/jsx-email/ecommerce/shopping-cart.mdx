## API Reference

| Prop      | Type                                            | Default           | Description                            |
| --------- | ----------------------------------------------- | ----------------- | -------------------------------------- |
| `theme`   | `Parameters<typeof __ShoppingCart>[0]["theme"]` | Component default | Renderer theme configuration.          |
| `items`   | `ShoppingCartItem[]`                            | Component default | Supplies the cart items.               |
| `variant` | `ShoppingCartVariant`                           | `"basic"`         | Selects the cart-row detail treatment. |
