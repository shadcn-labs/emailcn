## API Reference

| Prop      | Type                                           | Default           | Description                         |
| --------- | ---------------------------------------------- | ----------------- | ----------------------------------- |
| `theme`   | `Parameters<typeof __LineDivider>[0]["theme"]` | Component default | Renderer theme configuration.       |
| `align`   | `"left" \| "center" \| "right"`                | Component default | Configures the component's align.   |
| `content` | `DividerContent`                               | Component default | Configures the component's content. |
