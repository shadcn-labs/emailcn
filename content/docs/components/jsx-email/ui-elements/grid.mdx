## API Reference

| Prop      | Type                                                                                                           | Default         | Description                         |
| --------- | -------------------------------------------------------------------------------------------------------------- | --------------- | ----------------------------------- |
| `align`   | `"center" \| "left" \| "right"`                                                                                | `"center"`      | Configures the component's align.   |
| `cells`   | `string[]`                                                                                                     | -               | Configures the component's cells.   |
| `theme`   | `EmailTheme`                                                                                                   | `defaultTheme`  | Renderer theme configuration.       |
| `variant` | `"one-column" \| "two-columns" \| "three-columns" \| "four-columns" \| "one-three-split" \| "three-one-split"` | `"two-columns"` | Configures the component's variant. |
