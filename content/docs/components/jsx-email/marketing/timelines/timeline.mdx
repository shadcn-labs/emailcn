## API Reference

| Prop         | Type                                         | Default           | Description                            |
| ------------ | -------------------------------------------- | ----------------- | -------------------------------------- |
| `theme`      | `Parameters<typeof __Changelog>[0]["theme"]` | Component default | Renderer theme configuration.          |
| `items`      | `TimelineItem[]`                             | Component default | Configures the component's items.      |
| `layout`     | `"line" \| "boxed" \| "cards" \| "split"`    | Component default | Configures the component's layout.     |
| `alignment`  | `"left" \| "right"`                          | Component default | Configures the component's alignment.  |
| `appearance` | `"muted" \| "basic" \| "accent"`             | Component default | Configures the component's appearance. |
| `reverse`    | `boolean`                                    | Component default | Configures the component's reverse.    |
