## API Reference

| Prop        | Type                     | Default                                                                          | Description                           |
| ----------- | ------------------------ | -------------------------------------------------------------------------------- | ------------------------------------- |
| `theme`     | `EmailThemeTokens`       | `defaultTheme`                                                                   | Renderer theme configuration.         |
| `type`      | `"title" \| "paragraph"` | `"paragraph"`                                                                    | Configures the component's type.      |
| `columns`   | `1 \| 2`                 | `1`                                                                              | Configures the component's columns.   |
| `withIcons` | `boolean`                | `false`                                                                          | Configures the component's withicons. |
| `padding`   | `"regular" \| "large"`   | `"regular"`                                                                      | Configures the component's padding.   |
| `title`     | `string`                 | `"Section Title"`                                                                | Configures the component's title.     |
| `text`      | `string`                 | `"This is a paragraph used to present information in a clear and readable way."` | Configures the component's text.      |
| `column1`   | `string`                 | `"This is the first column of a two-column paragraph layout."`                   | Configures the component's column1.   |
| `column2`   | `string`                 | `"This is the second column of a two-column paragraph layout."`                  | Configures the component's column2.   |
| `iconSrc1`  | `string`                 | -                                                                                | Configures the component's iconsrc1.  |
| `iconAlt1`  | `string`                 | `"Icon 1"`                                                                       | Configures the component's iconalt1.  |
| `iconSrc2`  | `string`                 | -                                                                                | Configures the component's iconsrc2.  |
| `iconAlt2`  | `string`                 | `"Icon 2"`                                                                       | Configures the component's iconalt2.  |
