## API Reference

| Prop                    | Type                                 | Default           | Description                                       |
| ----------------------- | ------------------------------------ | ----------------- | ------------------------------------------------- |
| `theme`                 | `EmailThemeTokens`                   | Component default | Renderer theme configuration.                     |
| `overline`              | `string`                             | Component default | Configures the component's overline.              |
| `discount`              | `string`                             | Component default | Configures the component's discount.              |
| `code`                  | `string`                             | Component default | Configures the component's code.                  |
| `expiry`                | `string`                             | Component default | Configures the component's expiry.                |
| `backgroundImageSrc`    | `string`                             | Component default | Configures the component's backgroundimagesrc.    |
| `buttonLabel`           | `string`                             | Component default | Configures the component's buttonlabel.           |
| `buttonHref`            | `string`                             | Component default | Configures the component's buttonhref.            |
| `arrowIconSrc`          | `string`                             | Component default | Configures the component's arrowiconsrc.          |
| `pageBackgroundColor`   | `string`                             | Component default | Configures the component's pagebackgroundcolor.   |
| `headingColor`          | `string`                             | Component default | Configures the component's headingcolor.          |
| `codeBackgroundColor`   | `string`                             | Component default | Configures the component's codebackgroundcolor.   |
| `codeColor`             | `string`                             | Component default | Configures the component's codecolor.             |
| `buttonBackgroundColor` | `string`                             | Component default | Configures the component's buttonbackgroundcolor. |
| `buttonColor`           | `string`                             | Component default | Configures the component's buttoncolor.           |
| `variant`               | `CouponsWithContentOverlayedVariant` | Component default | Configures the component's variant.               |
