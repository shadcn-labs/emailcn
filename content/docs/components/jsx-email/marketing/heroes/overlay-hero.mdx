## API Reference

| Prop              | Type                                                                                                                     | Default           | Description                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------ | ----------------- | ------------------------------------------- |
| `theme`           | `Parameters<typeof __BlockHero>[0]["theme"]`                                                                             | Component default | Renderer theme configuration.               |
| `content`         | `HeroContent`                                                                                                            | Component default | Configures the component's content.         |
| `backgroundImage` | `HeroImage`                                                                                                              | Component default | Configures the component's backgroundimage. |
| `brand`           | `HeroBrand`                                                                                                              | Component default | Configures the component's brand.           |
| `treatment`       | `"aligned" \| "block" \| "gradient" \| "content-card"`                                                                   | Component default | Configures the component's treatment.       |
| `position`        | `\| "top-left"     \| "center-left"     \| "bottom-left"     \| "top-right"     \| "center-right"     \| "bottom-right"` | Component default | Configures the component's position.        |
| `bleed`           | `boolean`                                                                                                                | Component default | Configures the component's bleed.           |
| `reverse`         | `boolean`                                                                                                                | Component default | Configures the component's reverse.         |
