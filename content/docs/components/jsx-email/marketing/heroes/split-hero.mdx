## API Reference

| Prop             | Type                                                    | Default           | Description                                |
| ---------------- | ------------------------------------------------------- | ----------------- | ------------------------------------------ |
| `theme`          | `Parameters<typeof __ContainedSplitHero>[0]["theme"]`   | Component default | Renderer theme configuration.              |
| `content`        | `HeroContent`                                           | Component default | Configures the component's content.        |
| `images`         | `HeroImage[]`                                           | Component default | Configures the component's images.         |
| `brand`          | `HeroBrand`                                             | Component default | Configures the component's brand.          |
| `treatment`      | `"contained" \| "full-bleed" \| "overlay" \| "slanted"` | Component default | Configures the component's treatment.      |
| `imagePosition`  | `"left" \| "right"`                                     | Component default | Configures the component's imageposition.  |
| `slant`          | `"up" \| "down"`                                        | Component default | Configures the component's slant.          |
| `overlayContent` | `boolean`                                               | Component default | Configures the component's overlaycontent. |
