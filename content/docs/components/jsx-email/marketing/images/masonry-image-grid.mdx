## API Reference

| Prop            | Type                                                     | Default           | Description                               |
| --------------- | -------------------------------------------------------- | ----------------- | ----------------------------------------- |
| `theme`         | `Parameters<typeof __TwoColumnMasonryThree>[0]["theme"]` | Component default | Renderer theme configuration.             |
| `images`        | `GalleryImage[]`                                         | Component default | Configures the component's images.        |
| `feature`       | `GalleryImage`                                           | Component default | Configures the component's feature.       |
| `columns`       | `2 \| 3`                                                 | Component default | Configures the component's columns.       |
| `stackPosition` | `"left" \| "right"`                                      | Component default | Configures the component's stackposition. |
| `reverse`       | `boolean`                                                | Component default | Configures the component's reverse.       |
| `overlay`       | `boolean`                                                | Component default | Configures the component's overlay.       |
