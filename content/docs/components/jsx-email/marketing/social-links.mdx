## API Reference

| Prop           | Type                                             | Default           | Description                              |
| -------------- | ------------------------------------------------ | ----------------- | ---------------------------------------- |
| `theme`        | `Parameters<typeof __SimpleSocials>[0]["theme"]` | Component default | Renderer theme configuration.            |
| `title`        | `string`                                         | Component default | Configures the component's title.        |
| `description`  | `string`                                         | Component default | Configures the component's description.  |
| `items`        | `SocialLink[]`                                   | Component default | Configures the component's items.        |
| `presentation` | `"icons" \| "labels"`                            | Component default | Configures the component's presentation. |
| `container`    | `"none" \| "tile" \| "box" \| "pill"`            | Component default | Configures the component's container.    |
| `shape`        | `"square" \| "circle"`                           | Component default | Configures the component's shape.        |
| `outlined`     | `boolean`                                        | Component default | Configures the component's outlined.     |
| `direction`    | `"inline" \| "stacked"`                          | Component default | Configures the component's direction.    |
