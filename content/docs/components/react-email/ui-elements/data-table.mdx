## Usage

```tsx
import { DataTable } from "@/components/email/data-table";
```

```tsx
<DataTable
  columns={[
    { header: "Name", key: "name" },
    { header: "Status", key: "status", align: "right" },
  ]}
  rows={[
    { name: "Ada", status: "Active" },
    { name: "Linus", status: "Pending" },
  ]}
/>
```

## API Reference

| Prop      | Type                                                                                                                                              | Default            | Description                                        |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ | -------------------------------------------------- |
| `theme`   | `Parameters<typeof __BasicTable>[0]["theme"]`                                                                                                     | Component default  | Renderer theme configuration.                      |
| `variant` | `"basic" \| "four-columns" \| "change-indicators" \| "edit-actions" \| "logo-actions" \| "status-pills" \| "progress"`                            | `"basic"`          | Selects one of the original data-table treatments. |
| `columns` | `DataTableColumn<Row>[]`                                                                                                                          | Required for basic | Defines generic table columns and custom cells.    |
| `headers` | `string[]`                                                                                                                                        | Variant default    | Overrides the specialized variant's header labels. |
| `rows`    | `Row[] \| string[][] \| DataTableChangeRow[] \| DataTableEditRow[] \| DataTableLogoActionRow[] \| DataTableStatusRow[] \| DataTableProgressRow[]` | Variant dependent  | Supplies rows using the selected variant's shape.  |

`DataTableProps` is a discriminated union, so TypeScript narrows `rows` and the
other available props from the selected `variant`.
