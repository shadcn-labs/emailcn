## API Reference

| Prop      | Type             | Default           | Description                         |
| --------- | ---------------- | ----------------- | ----------------------------------- |
| `align`   | `GridAlign`      | Component default | Configures the component's align.   |
| `cells`   | `string[]`       | Component default | Configures the component's cells.   |
| `theme`   | `TailwindConfig` | Component default | Renderer theme configuration.       |
| `variant` | `GridVariant`    | Component default | Configures the component's variant. |
