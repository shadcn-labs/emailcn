## API Reference

| Prop        | Type                                             | Default           | Description                           |
| ----------- | ------------------------------------------------ | ----------------- | ------------------------------------- |
| `theme`     | `Parameters<typeof __ProductDetail>[0]["theme"]` | Component default | Renderer theme configuration.         |
| `product`   | `ProductDetails`                                 | Component default | Configures the component's product.   |
| `images`    | `Array<{ src: string; alt?: string }>`           | Component default | Configures the component's images.    |
| `treatment` | `"stacked" \| "side" \| "rating" \| "bleed"`     | Component default | Configures the component's treatment. |
| `placement` | `"left" \| "right"`                              | Component default | Configures the component's placement. |
