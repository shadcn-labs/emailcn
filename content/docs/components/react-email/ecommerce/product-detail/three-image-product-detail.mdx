## API Reference

| Prop             | Type                                                                                                             | Default           | Description                                |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ----------------- | ------------------------------------------ |
| `theme`          | `Parameters<typeof __ProductDetail>[0]["theme"]`                                                                 | Component default | Renderer theme configuration.              |
| `product`        | `ProductDetails`                                                                                                 | Component default | Configures the component's product.        |
| `images`         | `[     { src: string; alt?: string },     { src: string; alt?: string },     { src: string; alt?: string },   ]` | Component default | Configures the component's images.         |
| `ratingPosition` | `"top" \| "bottom" \| "aside"`                                                                                   | Component default | Configures the component's ratingposition. |
| `headerPosition` | `"default" \| "top"`                                                                                             | Component default | Configures the component's headerposition. |
