## API Reference

| Prop      | Type                                             | Default           | Description                         |
| --------- | ------------------------------------------------ | ----------------- | ----------------------------------- |
| `theme`   | `Parameters<typeof __TwoColumnGrid>[0]["theme"]` | Component default | Renderer theme configuration.       |
| `images`  | `GalleryImage[]`                                 | Component default | Configures the component's images.  |
| `columns` | `2 \| 3`                                         | Component default | Configures the component's columns. |
| `aspect`  | `"square" \| "portrait"`                         | Component default | Configures the component's aspect.  |
| `overlay` | `boolean`                                        | Component default | Configures the component's overlay. |
