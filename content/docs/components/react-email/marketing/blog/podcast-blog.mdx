## API Reference

| Prop    | Type                                            | Default           | Description                       |
| ------- | ----------------------------------------------- | ----------------- | --------------------------------- |
| `theme` | `Parameters<typeof __PodcastSplit>[0]["theme"]` | Component default | Renderer theme configuration.     |
| `post`  | `BlogPost`                                      | Component default | Configures the component's post.  |
| `width` | `"split" \| "full"`                             | Component default | Configures the component's width. |
