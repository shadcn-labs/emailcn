## API Reference

| Prop      | Type                                         | Default           | Description                         |
| --------- | -------------------------------------------- | ----------------- | ----------------------------------- |
| `theme`   | `Parameters<typeof __GridImage>[0]["theme"]` | Component default | Renderer theme configuration.       |
| `heading` | `string`                                     | Component default | Configures the component's heading. |
| `posts`   | `BlogPost[]`                                 | Component default | Configures the component's posts.   |
| `masonry` | `boolean`                                    | `false`           | Uses the masonry layout.            |
| `content` | `"image" \| "image-text" \| "boxed"`         | `"image"`         | Selects the post-card treatment.    |
