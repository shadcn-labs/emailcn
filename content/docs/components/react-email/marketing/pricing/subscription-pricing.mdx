## API Reference

| Prop      | Type                                                | Default           | Description                         |
| --------- | --------------------------------------------------- | ----------------- | ----------------------------------- |
| `theme`   | `Parameters<typeof __TwoColumnPricing>[0]["theme"]` | Component default | Renderer theme configuration.       |
| `plans`   | `SubscriptionPlan[]`                                | Component default | Configures the component's plans.   |
| `columns` | `1 \| 2`                                            | Component default | Configures the component's columns. |
