## API Reference

| Prop              | Type                                    | Default                                                                                                                             | Description                                 |
| ----------------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `theme`           | `TailwindConfig`                        | `defaultTheme`                                                                                                                      | Renderer theme configuration.               |
| `quote`           | `string`                                | `"“After migrating to emailcn, we increased efficiency by 40% across our transactional and marketing email development pipeline.”"` | Configures the component's quote.           |
| `author`          | `string`                                | -                                                                                                                                   | Configures the component's author.          |
| `role`            | `string`                                | -                                                                                                                                   | Configures the component's role.            |
| `company`         | `string`                                | `"Monarch"`                                                                                                                         | Configures the component's company.         |
| `avatar`          | `{ src: string; alt?: string }`         | -                                                                                                                                   | Configures the component's avatar.          |
| `logo`            | `{ src: string; alt?: string }`         | -                                                                                                                                   | Configures the component's logo.            |
| `layout`          | `"full-width" \| "centered" \| "split"` | `"full-width"`                                                                                                                      | Configures the component's layout.          |
| `avatarTreatment` | `"inline" \| "overlapping"`             | `"inline"`                                                                                                                          | Configures the component's avatartreatment. |
| `action`          | `{ href: string; label: string }`       | -                                                                                                                                   | Configures the component's action.          |
