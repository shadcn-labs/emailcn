## API Reference

| Prop                  | Type                                     | Default           | Description                                     |
| --------------------- | ---------------------------------------- | ----------------- | ----------------------------------------------- |
| `theme`               | `TailwindConfig`                         | Component default | Renderer theme configuration.                   |
| `logoSrc`             | `string`                                 | Component default | Configures the component's logosrc.             |
| `logoAlt`             | `string`                                 | Component default | Configures the component's logoalt.             |
| `logoHref`            | `string`                                 | Component default | Configures the component's logohref.            |
| `stats`               | `HeaderFinanceStat[]`                    | Component default | Configures the component's stats.               |
| `alignment`           | `HeaderWithLogoAndFinanceStatsAlignment` | Component default | Configures the component's alignment.           |
| `pageBackgroundColor` | `string`                                 | Component default | Configures the component's pagebackgroundcolor. |
| `backgroundColor`     | `string`                                 | Component default | Configures the component's backgroundcolor.     |
