## API Reference

| Prop              | Type                                                                                          | Default           | Description                                 |
| ----------------- | --------------------------------------------------------------------------------------------- | ----------------- | ------------------------------------------- |
| `theme`           | `Parameters<typeof __RollingStats>[0]["theme"]`                                               | Component default | Renderer theme configuration.               |
| `eyebrow`         | `string`                                                                                      | Component default | Configures the component's eyebrow.         |
| `label`           | `string`                                                                                      | Component default | Configures the component's label.           |
| `values`          | `string[]`                                                                                    | Component default | Configures the component's values.          |
| `position`        | `\| "center"     \| "top-left"     \| "top-right"     \| "bottom-left"     \| "bottom-right"` | Component default | Configures the component's position.        |
| `backgroundImage` | `{ src: string; alt?: string }`                                                               | Component default | Configures the component's backgroundimage. |
