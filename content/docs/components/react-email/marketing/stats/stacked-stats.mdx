## API Reference

| Prop                  | Type                                                        | Default           | Description                                     |
| --------------------- | ----------------------------------------------------------- | ----------------- | ----------------------------------------------- |
| `theme`               | `TailwindConfig`                                            | Component default | Renderer theme configuration.                   |
| `variant`             | `StackedStatsVariant`                                       | Component default | Configures the component's variant.             |
| `stats`               | `{ heading: string; value: string; description: string }[]` | Component default | Configures the component's stats.               |
| `pageBackgroundColor` | `string`                                                    | Component default | Configures the component's pagebackgroundcolor. |
| `backgroundColor`     | `string`                                                    | Component default | Configures the component's backgroundcolor.     |
| `accentColor`         | `string`                                                    | Component default | Configures the component's accentcolor.         |
| `headingColor`        | `string`                                                    | Component default | Configures the component's headingcolor.        |
| `textColor`           | `string`                                                    | Component default | Configures the component's textcolor.           |
| `dividerColor`        | `string`                                                    | Component default | Configures the component's dividercolor.        |
