## API Reference

| Prop                  | Type                    | Default           | Description                                     |
| --------------------- | ----------------------- | ----------------- | ----------------------------------------------- |
| `theme`               | `TailwindConfig`        | Component default | Renderer theme configuration.                   |
| `variant`             | `MilestoneStatsVariant` | Component default | Configures the component's variant.             |
| `heading`             | `string`                | Component default | Configures the component's heading.             |
| `value`               | `string`                | Component default | Configures the component's value.               |
| `unit`                | `string`                | Component default | Configures the component's unit.                |
| `currentLevel`        | `string`                | Component default | Configures the component's currentlevel.        |
| `nextLevel`           | `string`                | Component default | Configures the component's nextlevel.           |
| `remaining`           | `string`                | Component default | Configures the component's remaining.           |
| `progress`            | `number`                | Component default | Configures the component's progress.            |
| `pageBackgroundColor` | `string`                | Component default | Configures the component's pagebackgroundcolor. |
| `backgroundColor`     | `string`                | Component default | Configures the component's backgroundcolor.     |
| `cardBackgroundColor` | `string`                | Component default | Configures the component's cardbackgroundcolor. |
| `headingColor`        | `string`                | Component default | Configures the component's headingcolor.        |
| `textColor`           | `string`                | Component default | Configures the component's textcolor.           |
| `mutedTextColor`      | `string`                | Component default | Configures the component's mutedtextcolor.      |
| `progressTrackColor`  | `string`                | Component default | Configures the component's progresstrackcolor.  |
| `progressColor`       | `string`                | Component default | Configures the component's progresscolor.       |
