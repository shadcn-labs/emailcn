## API Reference

| Prop              | Type                                                     | Default           | Description                                 |
| ----------------- | -------------------------------------------------------- | ----------------- | ------------------------------------------- |
| `theme`           | `Parameters<typeof __ContentCtaFooter>[0]["theme"]`      | Component default | Renderer theme configuration.               |
| `brand`           | `FooterBrand`                                            | Component default | Configures the component's brand.           |
| `heading`         | `string`                                                 | Component default | Configures the component's heading.         |
| `description`     | `string`                                                 | Component default | Configures the component's description.     |
| `actions`         | `Array<{ href: string; label: string }>`                 | Component default | Configures the component's actions.         |
| `legal`           | `FooterLegal`                                            | Component default | Configures the component's legal.           |
| `placement`       | `"inline" \| "full-width" \| "overlap" \| "large-title"` | Component default | Configures the component's placement.       |
| `menuColumns`     | `0 \| 2 \| 3`                                            | Component default | Configures the component's menucolumns.     |
| `alignment`       | `"left" \| "center" \| "right"`                          | Component default | Configures the component's alignment.       |
| `backgroundImage` | `{ src: string; alt?: string }`                          | Component default | Configures the component's backgroundimage. |
